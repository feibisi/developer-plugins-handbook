# 设置

WordPress 提供了两个核心 API，使管理界面的构建变得简单、安全，并与 WordPress 管理后台的设计保持一致。

[设置 API](https://developer.wordpress.org/plugins/settings/settings-api/) 专注于为开发者提供创建表单和管理表单数据的方法。

[选项 API](https://developer.wordpress.org/plugins/settings/options-api/) 专注于使用简单的键/值系统来管理数据。

## 快速参考

查看使用设置 API 和选项 API [构建自定义设置页面](https://developer.wordpress.org/plugins/settings/custom-settings-page/)的完整示例。
