# JavaScript

JavaScript 是许多 WordPress 插件的重要组成部分。WordPress 核心捆绑了[多种 JavaScript 库](https://developer.wordpress.org/themes/basics/including-css-javascript/#default-scripts-included-and-registered-by-wordpress)。jQuery 是 WordPress 中最常用的库之一，因为它轻量且易于使用。您可以在插件中使用 jQuery 来操作 DOM 对象或执行 Ajax 操作。
