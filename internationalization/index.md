# 国际化

## 什么是国际化？

国际化是指开发插件时使其能够轻松翻译成其他语言的过程。国际化通常缩写为 `i18n`（因为在字母 i 和 n 之间有 18 个字母）。

## 为什么国际化很重要？

WordPress 在全球各地被使用，许多国家的主要语言并非英语。WordPress 插件中的字符串需要以特殊方式编码，以便能够轻松翻译成其他语言。作为开发者，您可能无法为所有用户提供*本地化*（即针对特定*区域*（地点）所需的文本更改和其他事项，如数字格式）；然而，翻译人员可以成功本地化主题，而无需修改源代码本身。

进一步阅读[如何国际化您的插件](https://developer.wordpress.org/plugins/internationalization/how-to-internationalize-your-plugin/)。
