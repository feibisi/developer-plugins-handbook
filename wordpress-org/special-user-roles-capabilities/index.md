# 特殊用户角色与权限

每位为插件推送代码或提供支持的人员都必须拥有**自己的**独立账户。这些账户不必是个人身份信息（例如，您可以将其命名为 PluginNameSupport1），但出于保护您自身的目的，所有账户必须由单个人使用。

对于插件，用户可拥有四种角色。所有角色都可以在插件页面的**高级视图**部分进行管理：

![插件页面界面，其中“高级视图”链接被高亮显示。](https://i0.wp.com/developer.wordpress.org/files/2020/08/advanced-view.jpg?resize=300%2C260&ssl=1)

根据需要，有字段可添加支持代表和提交者。

## 所有者

插件所有者由提交插件的人员自动设置。插件获批后，该人员将被添加为提交者（见下文）并标记为所有者。如需更改所有者，请向下滚动至 **危险区域** 部分，从下拉菜单中选择新所有者：

![转移此插件界面，包含新所有者选择器和“请转移 -插件名称-”按钮](https://i0.wp.com/developer.wordpress.org/files/2020/08/can-transger.jpg?resize=1024%2C548&ssl=1)

如果没有其他具有提交权限的用户，您需要先授予他们访问权限，然后才能转移插件。请记住，插件所有者应 **始终** 拥有其名下插件的提交权限。

如果您看到此消息，则说明您不是当前所有者，需要联系当前所有者进行所有权转移：

![消息：此插件当前由 -用户- 所有，他们可以选择将插件的所有权转移给您](https://i0.wp.com/developer.wordpress.org/files/2020/08/Owner.jpg?resize=1024%2C249&ssl=1)

如果原始所有者已无法联系，您可以联系插件团队寻求帮助。

## 提交者

拥有提交权限的人员能够通过 SVN 推送代码，并可就插件向插件目录团队提出正式请求。

任何拥有提交权限的人员都有权请求关闭插件，并能够添加或移除其他人员的提交权限。此操作可通过侧边栏的**高级页面**完成：

![添加提交者的界面，包含一个输入框和旁边的“添加”按钮](https://i0.wp.com/developer.wordpress.org/files/2021/02/Commit.jpg?resize=302%2C133&ssl=1)

在论坛中，这些人被标记为“插件作者”，并能够将与其插件相关的帖子标记为已解决。

除了在论坛中回复插件支持主题时显示的“插件作者”标签外，拥有提交权限并不会对外公开显示。若要在插件的“贡献者与开发者”部分列出，并将插件包含在 WordPress.org 个人资料中，用户必须被列为贡献者（请参阅后续章节）。

添加和移除提交权限只能由现有的提交者执行。

## 支持代表

支持代表**不具备**直接管理插件本身的额外权限。他们无法请求更改插件在目录中的状态。不过，他们将在论坛中被标记为官方支持人员，这有助于用户了解是谁在提供帮助。

![添加支持代表的界面，包含一个输入框和旁边的“添加”按钮](https://i0.wp.com/developer.wordpress.org/files/2021/02/Support.jpg?resize=317%2C140&ssl=1)

在论坛中，他们被标记为“插件支持”，并有权将与自家插件相关的帖子标记为已解决。

他们会在插件页面上显示，且该插件会作为支持代表出现在他们的个人资料页中。

此状态的添加和移除只能由现有提交者操作。

## 贡献者

贡献者不具备直接管理插件本身的额外权限。他们_无法_请求更改插件在目录中的状态。

在论坛中，他们被标记为“插件贡献者”，并有权将涉及他们插件的帖子标记为已解决。

贡献者会在插件的“贡献者与开发者”部分公开列出，并且该插件会显示在用户 WordPress.org 个人资料的插件列表中。

要成为贡献者，用户必须被列入插件 `readme.txt` 文件中的_贡献者_部分。

虽然通常会将参与插件构思或原始贡献的人员添加为贡献者，但您无需为插件添加任何超出您舒适范围的访问权限的人员。
