# 使用论坛

通过免费的插件托管服务，所有插件开发者都可以使用支持论坛和评价功能来管理他们的插件。

开发者在论坛活动时必须遵守[论坛准则](https://wordpress.org/support/guidelines/)，这可能导致对如何管理插件付费版本产生困惑。

## 本准则适用于所有人

插件所有者是插件的最终控制者。然而，如果其他开发者或支持人员违反准则，插件将面临被警告和关闭的风险。论坛或插件团队没有责任管理您的公司/员工。如果支持人员创建傀儡账号，插件开发者将被通知并需采取行动。如果他们不能或不愿约束其同事，我们将停止托管其插件，并可能封禁该公司。

**_所有人_** 都必须遵守准则。绝无例外。

## 目录并非交易市场

插件目录与论坛并非用于销售或支持非托管于此处的产品。若您在我们系统中注册插件的唯一目的是商业推广，请知悉此行为不会获得任何特殊待遇。

## 用户并非客户

WordPress.org 上的用户并非您的客户，应将其视为用户。这意味着您**不能**向他们索要私人联系信息，不能主动登录他们的网站，也不能向他们收取帮助费用。这是为了您的法律保护，我们禁止这些行为。即使存在购买合同，您仍需对登录其网站造成的损害负责。未经购买授权而登录则风险更高。

若对方是客户（即已购买您的付费产品并在免费论坛发帖），您可以且应当提醒他们：您无法在 WordPress.org 论坛提供支持，并附上专业支持服务的链接。同样，您可以告知用户无法在论坛提供免费支持，并引导至您的网站获取完整说明。

## 您可以要求用户在您自己的系统中提交工单

如果您提供的服务需要账户，这一点尤其适用。您与用户之间已存在既定的关系，要求他们为服务支持提交工单是合理且允许的。如果他们是实际付费客户，您也可以要求他们提交工单。

如果您希望提供更高级别的付费支持服务，告知用户已超出免费支持范围是可以接受的。在这种情况下，我们建议您在自述文件中披露此信息，并在网站上设置专门页面详细说明免费帮助的范围。

对于其他所有情况，如果您在免费论坛中帮助他人，我们期望您直接在论坛内提供帮助。

## 您无需提供免费支持

如果您不想提供免费支持，您没有义务这样做。我们强烈建议您在自述文件中明确说明这一点（最好在描述顶部，以免被忽略），我们将支持您的决定。

请注意，因此给您留下差评的评论不会被删除。当然，您可以回复这些评论，解释您不提供支持的原因，并说明您已披露这一事实。

## 允许对高级版本进行评价（在合理范围内）

这可能会令人困惑。

我们认为，只要满足以下条件，用户有权留下包含插件高级版本详情的评价：

1. 插件本身在自述文件或插件设置页面内推销/推广高级版本
2. 评价包含插件功能/可用性的详细信息
3. 评价**不**仅仅是对推销行为的抱怨
4. 评价**不**包含对开发者的骚扰、辱骂、粗俗言论或其他攻击
5. 评价**不**针对未托管在 WordPress.org（全部或部分）的纯高级版插件

我们不会容忍对开发者的滥用或骚扰，正如我们不会容忍对用户一样。也就是说，负面评价本身并不总是带有攻击性。有时人们只是不喜欢你的插件，这没关系。

## 允许公司拥有多个账户（在合理范围内）

这里真正的问题是，用户不喜欢与“MarvelTech100”交流，而更愿意与卡罗尔·丹弗斯对话。没有面孔的自动化机器人很难让人产生联系感。

话虽如此，拥有一个公司账户来管理你的插件是完全合乎逻辑且合理的。但在这种情况下，该账户仅作为插件/主题的**所有者**，**不允许**在论坛上使用。

如果你想拥有两个账户，一个是你的个人账户，另一个是“公司中的你”，这完全没问题。人们只是更喜欢与人交流。

## 禁止共享账户

与此相关，请勿共享账户。这会导致混乱、纠纷，并且当团队中有人违反准则时，很难理清你的身份。这从来不会有好结果。
