# 元数据

元数据是关于信息的信息。在 WordPress 中，它指的是与文章、用户、评论和分类相关联的信息。

鉴于 WordPress 中元数据存在多对一的关系，您的选择几乎是无限的。您可以拥有任意数量的元选项，并且几乎可以在其中存储任何内容。

本章将讨论[管理文章元数据](https://developer.wordpress.org/plugins/metadata/managing-post-metadata/)、[创建自定义元框](https://developer.wordpress.org/plugins/metadata/custom-meta-boxes/)以及[渲染文章元数据](https://developer.wordpress.org/plugins/metadata/rendering-post-metadata/)。
