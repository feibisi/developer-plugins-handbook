# 开发者工具

插件开发过程中可使用多种辅助工具。部分工具需在开发环境中运行（如 [xdebug](https://xdebug.org/)、[PHPCS](https://github.com/WordPress/WordPress-Coding-Standards) 等），同时也有优秀工具可直接在 WordPress 内部运行，帮助您规范构建项目并诊断问题。本章将重点介绍浏览器内置工具。
