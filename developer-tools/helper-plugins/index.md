# 辅助插件

## 插件检查工具

插件检查工具用于测试您的插件是否符合 WordPress.org 插件目录的必备标准。通过此插件，您可以运行新插件提交所需的大部分检查，并验证您的插件是否满足要求。

此外，该工具还会标记插件开发最佳实践中的违规行为或潜在问题，涵盖从国际化函数正确使用等基础要求，到可访问性、性能和安全最佳实践。

[访问插件检查工具](https://wordpress.org/plugins/plugin-check/)

## 查询监控器

查询监控器是面向 WordPress 开发者的调试插件。您可以查看数据库查询、钩子、条件判断、HTTP 请求、重定向等调试与性能信息。它具备其他调试插件所没有的高级功能，包括自动 AJAX 调试和按插件或主题筛选信息的能力。

[访问查询监控器](https://wordpress.org/plugins/query-monitor/)
