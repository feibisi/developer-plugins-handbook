# 自定义文章类型

WordPress 将文章类型存储在 `posts` 表中，允许开发者注册自定义文章类型以及已存在的类型。

本章将展示如何[注册自定义文章类型](https://developer.wordpress.org/plugins/post-types/registering-custom-post-types/)，以及如何[从数据库检索其内容并呈现给公众](https://developer.wordpress.org/plugins/post-types/working-with-custom-post-types/)。
